# Kwarta - Budget Tracker Tech Stack

## Overview

Kwarta is a personal finance and budget tracking web application focused on helping users manage income, expenses, savings goals, and financial insights through a modern dashboard.

## Recommended Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Forms & Validation
- React Hook Form
- Zod

### Backend & Database
- Supabase
- PostgreSQL

### Charts & Analytics
- Recharts

### Deployment
- Vercel
- Supabase

### PWA / Mobile Install
- Web App Manifest
- Service Worker
- iOS Apple Web App metadata
- Apple touch icon and maskable app icons

## MVP Features

### Authentication
- Register
- Login
- Logout

### Transactions
- Add income
- Add expenses
- Edit transactions
- Delete transactions

### Categories
- Create categories
- Edit categories
- Delete categories

### Dashboard
- Total income
- Total expenses
- Current balance
- Spending charts

### Mobile App Experience
- Add to Home Screen support on iPhone
- Standalone display mode
- App icon and theme color
- Basic offline shell caching

### Budgets
- Monthly budget limits
- Budget progress tracking

## Future Enhancements
